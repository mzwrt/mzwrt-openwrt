# MzWrt · CMCC RAX3000M

基于 OpenWrt 24.10.7 · MediaTek Filogic (MT7981)

---

## 本次优化（2026-11）

### 稳定与安全
- 面向 512MB 长期挂机：收敛内核无关子系统（memcg / MPTCP / io_uring / coredump 等），内核改为体积优先
- OpenSSL：关闭 TLS compression 与 AFALG/devcrypto 引擎，降低加密路径异常风险；软件路径保留 ChaCha 优先
- 关闭 Ruby YJIT；无线改为 `wpad-openssl`；去掉双 NTFS（保留 ntfs3）、SSR 残留符号等冗余包
- 补齐 AdGuardHome 二进制与 eMMC 用 `f2fsck`
- conntrack 调整为 32768，增加 `vm.min_free_kbytes`，降低 Clash/AGH 同开时的 OOM 概率

### 国内：低延迟 · 高速率
- 默认开启软/硬 **flow offloading**（MT7981 硬件转发）
- 开启 **packet_steering**，减轻双核单边打满造成的延迟毛刺
- 保留 BBR + `fq_pie`（按产品设定）

### 跨境：OpenClash 吞吐
- 放大 TCP 窗口（最大 8MB），`tcp_slow_start_after_idle=0`，并启用 MTU probing / TCP Fast Open
- 出站建议：**Rule 模式 + 大陆 DIRECT + Fake-IP/TUN + 协议栈 System**，以便吃到本机 BBR
- 详细说明见固件内：`/etc/mzwrt/openclash-tuning.txt`

### 编译
- 版本由 `mzwrt/config` 的 `version.conf` 统一维护（当前 24.10.7）
- 本仓库 Actions 直接编译并发布 Release

## 使用提示

- 默认源：清华大学镜像
- Wi‑Fi 国家：首选 **CN**，备选 US / CA
- USB / EMMC 建议定期 `fstrim`，延长存储寿命
- NAND / EMMC 刷机说明见仓库 `Flash-NAND`、`Flash-EMMC`
